# Границы проекта (Scope)

## Что входит в проект

### Функциональность (O2A Process)
- **Полный цикл B2B-заявок (ШПД):** Прохождение 5 фаз жизненного цикла (Инициация, Pre-sale, Sale, Fulfillment, Post-sale).
- **Проверка технической возможности (ТВ):** Обработка адресов подключения с тремя исходами (есть, есть со стройкой, нет).
- **Динамическая маршрутизация:** Автоматическое определение маршрута заявки по параметрам (скорость, тариф, задолженность, признак госзаказчика, CAPEX, сегмент).
- **Параллельные согласования:** Профильные согласования (юридическое, финансовое, закупочное) и управленческое согласование для крупных сделок.
- **Управление SLA и эскалации:** Нормативы на этапы, паузы SLA по закрытому справочнику с предельным сроком (10 дней), система предупреждений.
- **Управление отменами:** Гибкая логика отмен по уровням обязательств (0 — до договора, 1 — договор подписан, 2 — работы начаты / компенсация затрат).
- **Реалтайм-уведомления:** Доставка алертов операторам через WebSockets.
- **Документы и экспорт:** Загрузка вложений, генерация печатных форм договоров/актов и экспорт отчетов (CSV/PDF).
- **Аудит:** Неизменяемый журнал истории изменений (`AuditLog`).

### Сценарии и крайние случаи
- **SC-00:** Регистрация компании-клиента и добавление сотрудников.
- **SC-01:** Стандартная заявка (без согласований).
- **SC-02:** Заявка с дополнительными согласованиями и возвратом на доработку.
- **SC-03:** Крупная / нестандартная заявка (со стройкой и управленческим согласованием).
- **Крайние случаи (EC-01 — EC-25):** Отказ по ТВ, возвраты, отмены по соглашению сторон, нарушение SLA.

### Mock-интеграции (Экосистема МТС)
- **Mock CRM:** Данные клиента, сегмент, менеджер, признак госзаказчика.
- **Mock Биллинг:** Проверка баланса и задолженности.
- **Mock Справочник клиентов:** Валидация ИНН при регистрации компании.

### Артефакты поставки
- Docker Compose манифесты для локального запуска всей системы одной командой.
- Документированные OpenAPI-контракты.
- Набор автотестов (Unit, Testcontainers, Playwright E2E).

## Что НЕ входит в проект
- Реальные контуры и производственные системы МТС.
- AI-агенты и автоматическая генерация документов с помощью LLM.
- Отдельный мобильный клиент (фокус строго на веб-панели оператора и клиентском интерфейсе в её рамках).
- Автоматический биллинг, выставление реальных счетов и эквайринг.
- Долгосрочное техническое обслуживание после успешной активации услуги.

## Границы процесса
**Начало:** представитель корпоративного клиента создаёт заявку на подключение.  
**Конец:** услуга активирована, акт подписан, заявка закрыта.
