# Границы проекта

## Что входит в проект

### Функциональность
- Обработка заявок на подключение B2B-услуг
- Проверка технической возможности
- Маршрутизация заявок по параметрам
- Согласования: юридическое, финансовое, закупочное, управленческое
- Контроль SLA для этапов
- Уведомления участников
- История изменений заявки
- Панель оператора

### Сценарии
- Стандартная заявка
- Заявка с дополнительными согласованиями
- Крупная/нестандартная заявка

### Интеграции
- Mock CRM
- Mock биллинг
- Mock справочник клиентов

### Артефакты
- README и инструкция по запуску
- API-контракты (OpenAPI)
- Автотесты ключевых сценариев
- Демонстрация сквозного сценария

## Что НЕ входит в проект

- Реальные системы МТС
- AI-агенты
- Портал клиента (внешний UI)
- Мобильное приложение
- Биллинг и выставление счетов
- Долгосрочное обслуживание услуг
- Расторжение договоров

## Границы процесса

**Начало:** клиент инициирует заявку на подключение услуги.
**Конец:** услуга подключена и активирована, заявка закрыта.

**Вне границ:** обслуживание после подключения, выставление счетов, расторжение.

## Внешние системы

Все внешние системы эмулируются через mock-сервисы:
- **CRM** — данные клиента и история
- **Биллинг** — тарифы и баланс
- **Справочник клиентов** — справочник клиентов

Доступ к реальным системам не требуется.
