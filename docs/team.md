# Команда и роли

## Участники

| Участник | Роль | Зона ответственности |
|---|---|---|
| **Дима** | Тимлид + Системный аналитик | Доменная модель, статусы, маршрутизация, SLA, архитектура, координация, ревью |
| **Егор** | Бизнес-аналитик + Фронтендер | Бизнес-процессы, роли, сценарии, UI-требования, веб-панель оператора, клиентские сценарии |
| **Денис** | Бэкендер (API & BFF) | API Gateway (FastAPI), DTO, валидация (Pydantic), интеграции с Mock-сервисами, WebSockets (реалтайм-уведомления), OpenAPI |
| **Кирилл** | Бэкендер (Доменное ядро) | Транзакционное ядро (Java 21 / Spring Boot), доменная логика, СУБД, движок маршрутизации, SLA, история изменений, документы |
| **Салават** | DevOps + QA | Контейнеризация (Docker, Docker Compose), CI/CD (GitHub Actions), mock-сервисы, QA-стратегия, интеграционные и E2E-тесты |

## Стек по ролям

### Дима
- **Документация и аналитика:** Markdown, Mermaid, UML-диаграммы.
- **Проектирование:** Спецификации бизнес-логики, FSM (конечные автоматы переходов статусов), архитектурный надзор.

### Егор
- **Аналитика:** Бизнес-процессы, сценарии (SC-00...SC-03), требования к интерфейсу.
- **Frontend:** React, Vite, Axios, React Router, UI-библиотека (Tailwind / MUI), React Testing Library.

### Денис (API & BFF)
- **Язык / Фреймворк:** Python 3.11+, FastAPI, Uvicorn.
- **Валидация / Схемы:** Pydantic v2.
- **Асинхронность:** WebSockets для доставки реалтайм-уведомлений в UI.
- **Интеграции:** HTTP-клиенты (`httpx`), паттерны взаимодействия с Mock-сервисами.
- **Документация API:** OpenAPI / Swagger UI.

### Кирилл (Доменное ядро)
- **Язык / Фреймворк:** Java 21, Spring Boot 3.x, Spring Data JPA.
- **БД и Миграции:** PostgreSQL 16, Flyway.
- **Бизнес-логика:** Движок маршрутизации заявок, статусный автомат, контроль SLA (`@Scheduled` + `Clock`).
- **Безопасность и Аудит:** Spring Security + JWT, неизменяемый аудиторский лог (`AuditLog`), управление вложениями и генерация печатных форм документов.
- **Тестирование:** JUnit 5, Testcontainers.

### Салават (DevOps & QA)
- **Инфраструктура:** Docker, Docker Compose, GitHub Actions, развертывание на сервере.
- **Мониторинг и логирование:** Spring Actuator, SLF4J + Logback.
- **Тестирование:** JUnit 5, Testcontainers, Playwright (E2E), WireMock (моки внешних систем).
- **Контроль качества:** JaCoCo (покрытие кода тестами).

## Правила работы

- **Перекрёстное ревью:** Минимум 1 аппрув от коллег; автор не мержит свой код в главную ветку самостоятельно.
- **Архитектурный арбитраж:** Дима принимает финальное решение при спорных архитектурных или продуктовых вопросах.
- **Владение модулями:** Каждый участник несет персональную ответственность за свой компонент (Денис — шлюз, Кирилл — ядро, Егор — фронтенд, Салават — инфраструктура/тесты, Дима — аналитика/координация).
