# infra/seed

Данные для демо и сквозных тестов. Сид в БД и заглушки моков должны совпадать по ИНН: за соответствие отвечает этот файл.

| Что | Где | Кто |
|---|---|---|
| Список пользователей и компаний, соответствие ИНН | этот файл | Салават |
| Миграции `db/demo` (пользователи, роли, компании) | `core-service/src/main/resources/db/demo` | Денис |
| Демо-заявки через API | `infra/seed/demo-requests/` | Денис |

Миграции `db/demo` подключаются только в профилях `DEMO` и тестовом ([integrations.md](../../docs/system/integrations.md), 5.1). Пароль у всех демо-пользователей один: в миграции лежит хеш BCrypt (стоимость 10), для тестов значение передаётся переменной `DEMO_PASSWORD` (файл с ней добавим вместе со сквозными тестами). Почта пользователя — `<логин>@demo.test`.
